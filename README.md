# Mi archivo personal · Portfolio

Borrador experimental para GitHub Pages.

## Contenido
- Portada editorial con acceso claro al archivador.
- Archivador interactivo con cajón animado.
- Seis fichas de proyecto **de ejemplo**, sustituibles por trabajos reales.
- Lupa opcional en ordenadores (efecto de ampliación con leve refracción). Se activa desde el botón «LUPA: OFF».
- Adaptación a móvil, navegación con teclado y opción de movimiento reducido.

## Para revisar
Abre `index.html` en un navegador, o publica la rama `main` y la carpeta `/(root)` desde **Settings → Pages** del repositorio.

## Para editar
- `index.html`: textos y estructura.
- `styles.css`: composición, colores y animaciones.
- `app.js`: lista `projects`, carpeta, transiciones y lupa.

**Importante:** todos los proyectos y descripciones son ejemplos provisionales. No se han incorporado imágenes ni trabajos del usuario. Sin infraestructura ni servicios de pago.
